# Boldwool — Fibre Fidelity keten flow

Public invite site for Boldwool’s cooperative textile-upcycling **keten** (supply-chain flow).
Enthusiasts & makers first. Not a CapEx / factory pitch.

## Live site (GitHub Pages)

**https://lennart1970.github.io/boldwool-keten-flow/**

Source: `main` branch · Pages folder: `/docs`.

## Claims (strict)

Ladder only:

1. Industrial felt fabric (Havivank)
2. Artisan proef-eindproducten
3. Open Q = follow-up processability

**Off this page:** ultrasonic wash, SWFP-NL, MIT wash study, CapEx / new mill.

Copy source: [`KETEN-COPY.md`](./KETEN-COPY.md).
