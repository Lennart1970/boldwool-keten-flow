# wool_mail — handoff with Project wool

Division of labour between the inbox bot and this Project (wool / Boldwool coordinator).

## wool_mail (Grok Bot)

Keeps all execution that needs Lennart's own Outlook login:

- Reading mail
- Triage
- Drafting
- Filing
- Sending only when he explicitly says so

Passes relevant mail content on to Lennart and, where useful, to this Project.

## This Project (wool)

Owns:

- Repo work
- Code
- Documentation

Never gets mailbox access or credentials.
